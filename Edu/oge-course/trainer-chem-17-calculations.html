Алгоритм решения задач по уравнению

  • 1. Запиши уравнение и расставь коэффициенты.
  • 2. Найди n (моль) известного вещества: n = m / M (или n = V / 22,4 для газов при н.у.).
  • 3. Используй пропорцию по уравнению: коэффициенты показывают мольные соотношения.
  • 4. Найди n искомого вещества: n(искомое) = n(известное) · (коэф. искомого) / (коэф. известного).
  • 5. Переведи моль в нужную величину: m = n · M, V = n · 22,4 (для газов при н.у.).

Полезные молярные массы (M, г/моль):

  • H2 — 2; O2 — 32; N2 — 28; CO2 — 44; H2O — 18
  • HCl — 36,5; H2SO4 — 98; HNO3 — 63; NaOH — 40; KOH — 56; Ca(OH)2 — 74
  • NaCl — 58,5; Na2SO4 — 142; CaCO3 — 100; CaCl2 — 111; AgCl — 143,5; BaSO4 — 233
  • CuO — 80; Fe2O3 — 160; ZnO — 81; Al2O3 — 102
  • Cu — 64; Fe — 56; Zn — 65; Al — 27; Mg — 24; Ca — 40; Na — 23; K — 39

Молярный объём газа при н.у.: Vm = 22,4 л/моль.
