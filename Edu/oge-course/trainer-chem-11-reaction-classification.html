Типы химических реакций

По числу и составу веществ:

Соединения

Из нескольких → одного. A + B → AB

2H2 + O2 → 2H2O
CaO + CO2 → CaCO3
Разложения

Из одного → нескольких. AB → A + B

2H2O2 → 2H2O + O2
CaCO3 → CaO + CO2↑
Замещения

Простое + сложное → новое простое + новое сложное.

Zn + 2HCl → ZnCl2 + H2↑
Fe + CuSO4 → FeSO4 + Cu
Обмена

Два сложных меняются «частями». AB + CD → AD + CB

NaOH + HCl → NaCl + H2O
AgNO3 + NaCl → AgCl↓ + NaNO3

По изменению степеней окисления (ОВР):

  • ОВР — изменяются СО атомов. Все реакции замещения — ОВР. Реакции с участием простых веществ обычно ОВР.
  • Не ОВР — реакции обмена между сложными веществами без простых; нейтрализация; ионные реакции с осадком/газом.

По тепловому эффекту: экзотермические (выделяют тепло, +Q или ΔH<0) — горение, нейтрализация. Эндотермические (поглощают тепло, −Q) — разложение CaCO3, синтез NO.
