С кем реагируют простые вещества

Металлы реагируют с:

  • Кислотами (если стоят до H в ряду активности): Mg + 2HCl → MgCl2 + H2↑
  • Кислотными оксидами (активные металлы): 2Mg + CO2 → 2MgO + C
  • Неметаллами: 2Fe + 3Cl2 → 2FeCl3, 2Cu + O2 → 2CuO
  • Солями менее активных металлов: Fe + CuSO4 → FeSO4 + Cu↓
  • Водой (Na, K, Ca — сразу; Fe, Mg — при нагревании; Cu, Ag — не реагируют)

Неметаллы реагируют с:

  • Металлами: S + Fe → FeS, 3Cl2 + 2Al → 2AlCl3
  • Водородом (галогены, кислород, сера, азот при нагревании)
  • Кислородом (горение): S + O2 → SO2, 4P + 5O2 → 2P2O5
  • Друг с другом: 2H2 + O2 → 2H2O, S + 3F2 → SF6

Что НЕ реагирует: соли с солями (если оба — растворимы и не дают осадка); металлы между собой (только сплавы); кислородосодержащие соли (нитраты, сульфаты) — ме́жду собой не реагируют без катализатора.
