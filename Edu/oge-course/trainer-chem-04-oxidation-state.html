Правила определения степени окисления

1. В простом веществе (O₂, Cl₂, Fe) степень окисления = 0.

2. Сумма всех степеней окисления в нейтральной молекуле = 0; в ионе = заряду иона.

3. Постоянные степени окисления (запомнить):

  • F всегда −1
  • O почти всегда −2 (исключения: пероксиды H₂O₂ → −1; OF₂ → +2)
  • H: +1 с неметаллами; −1 с активными металлами (NaH, CaH₂)
  • Щелочные металлы (Li, Na, K): всегда +1
  • Щёлочноземельные (Mg, Ca, Ba): всегда +2
  • Al: всегда +3

4. Высшая (положительная) степень окисления = номеру группы (для главных подгрупп). Низшая (отрицательная) для неметаллов = номер группы − 8.

Пример (S в H₂SO₄): H +1, O −2. Сумма: 2·(+1) + x + 4·(−2) = 0 → x = +6.
