Что нужно проверять

Утверждение верно для обоих элементов, только если оно одновременно верно для каждого из них. Проверяй каждое отдельно.

Что обычно спрашивают:

  • Число электронных слоёв в атоме (= номер периода)
  • Число электронов на внешнем уровне (= номер группы для главных подгрупп)
  • Сравнение радиусов атомов
  • Тип простого вещества (металл / неметалл / двухатомная молекула)
  • Высшая степень окисления / валентность
  • Формула высшего оксида (Э2O — для I группы, ЭO — для II, Э2O3 — для III, ЭO2 — для IV, и т.д.)
  • Тип образуемых гидроксидов (основный / амфотерный / кислотный)

Подсказка: ловушка #1 — утверждение верно для одного элемента и неверно для другого. Ловушка #2 — утверждение про простое вещество (например, «двухатомная молекула»), которое верно только для одного из пары.
