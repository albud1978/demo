Логика цепочек превращений

Типичная цепочка металла: металл → оксид → гидроксид (или соль) → другая соль → новый гидроксид

  • Cu → CuO → CuSO4 → Cu(OH)2: 1) горение Cu в O2; 2) CuO + H2SO4; 3) CuSO4 + 2NaOH
  • Na → Na2O → NaOH → Na2CO3: 1) Na + O2; 2) Na2O + H2O; 3) 2NaOH + CO2

Типичная цепочка неметалла: неметалл → оксид → кислота → соль

  • S → SO2 → SO3 → H2SO4 → Na2SO4
  • C → CO2 → H2CO3 → Na2CO3

Подсказка: ищи логику — какой класс получается из предыдущего? (металл → оксид; оксид + H2O → гидроксид; гидроксид + кислота → соль; соль + щёлочь → другая соль или нерастворимое основание).
