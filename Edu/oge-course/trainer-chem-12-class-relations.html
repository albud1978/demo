Подход к задаче

Прочитай каждую пару реагентов и подумай, что они дадут в продукте. Затем найди соответствующую формулу в правом столбце.

Полезные правила:

  • Кислота + основание → соль + H2O (нейтрализация)
  • Кислотный оксид + основание → соль + H2O
  • Кислота + металл (до H) → соль + H2↑
  • Соль + соль → новая соль + новая соль (если осадок)
  • Соль + щёлочь → нерастворимый гидроксид + новая соль
  • Сильная кислота + карбонат → CO2↑ + H2O + соль
