Алгоритм решения задач №22

Шаг 1. Записать уравнение реакции, расставить коэффициенты.

Шаг 2. Найти массу растворённого вещества: m(в-ва) = m(р-ра) · ω / 100%.

Шаг 3. Найти количество вещества: n = m / M.

Шаг 4. По уравнению найти количество искомого продукта (через коэффициенты): n(прод) = n(в-ва) · k(прод) / k(в-ва).

Шаг 5. Найти массу продукта: m(прод) = n(прод) · M(прод).

m(р-ра) → m(в-ва) → n(в-ва) → n(прод) → m(прод)

Молярные массы для расчётов: M вычисляется как сумма атомных масс, округлённых до целых (кроме Cl=35,5).
